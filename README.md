# Forge Fitness — Gym Website

A modern, responsive gym website built to showcase fitness facilities, membership plans, trainers, and contact information. This project was created as a frontend website demonstration for a fitness business.

## Live Demo

🔗 Live Website: [fitness-website-2026.vercel.app]

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Navigation between website sections
- Hero section introducing the fitness brand
- About and gym facilities sections
- Membership plan presentation
- Trainer showcase
- Contact section with enquiry options
- WhatsApp enquiry integration (if configured)

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- Git and GitHub
- Vercel for deployment

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/babita010203/fitness_website.git
```

Replace `https://github.com/babita010203/fitness_website.git` with your repository's GitHub URL.

### 2. Navigate to the project directory

```bash
cd fitness_website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Purpose

This project demonstrates frontend development skills, responsive UI design, component-based development, and deployment using Vercel.

It is a demonstration project, not a claim of completed work for a real gym client.
